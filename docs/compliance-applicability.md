# Regulatory and framework applicability — MSP Sentinel AI 3.0

These 12 references are conditional governance mappings, **not certifications or evidence of production compliance**. Verify applicability with legal and sector specialists.

| Reference | Possible monitoring relevance | Limit |
|---|---|---|
| CERT-In Directions 2022 | Incident records and reporting workflows | Demo has no regulated reporting implementation |
| SEBI CSCRF 2024 | Cyber monitoring and resilience | Entity-specific |
| RBI IT and Cyber | Risk governance and SOC oversight | RBI entity category matters |
| DPDP Act 2023 | Data minimization and breach governance | Verify commenced provisions |
| NSE/BSE technology audit | Monitoring and access review | Exchange/member-specific |
| NPCI/UPI | Payment-system incident monitoring | Participant-specific |
| SEBI PFUTP 2003 | Securities fraud context | Not an MSP cybersecurity monitoring mandate |
| ISO/IEC 27001:2022 | Threat intelligence, logging, monitoring and access controls | Scoped ISMS/SoA required |
| ISO/IEC 27090 | Requested identifier needs independent verification | No validated applicability claim |
| MITRE ATT&CK | Threat behavior and detection hypotheses | Not a regulation |
| ISO/IEC 42001:2023 | Governance of AI-assisted analysis | Conditional AI management-system scope |
| NIST CSF 2.0 | Govern, Identify, Protect, Detect, Respond, Recover | Voluntary unless adopted or required |

## Evidence needed for real-world assurance

Source licensing and provenance, written tenant authorization, SSO/RBAC, tenant isolation tests, SIEM connector validation, logging and retention, model-review procedures, security testing, incident response records, change control and rollback. The current demo does not satisfy these by itself.
